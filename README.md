Library Management System Using Java

About the Project

The Library Management System is a console-based Java application developed using Core Java. It helps manage library books through a simple menu-driven interface.

Features

- Add new books
- Display all books
- Search books by ID or title
- Issue and return books
- Display available and issued books
- Sort books alphabetically
- Delete book records
- Handle invalid input using exception handling

Technologies Used

- Java
- Eclipse IDE
- Java Collection Framework
- Object-Oriented Programming
- Exception Handling
- Data Structures and Algorithms

Java Concepts Implemented

- Classes and Objects
- Encapsulation
- Methods and Modular Programming
- ArrayList
- HashMap
- Comparator
- Searching and Sorting
- try-catch-finally
- Custom Exceptions

Project Structure

- Main.java: Menu-driven interface
- Book.java: Stores book details
- Library.java: Implements library operations
- BookNotFoundException.java: Handles missing book records

How to Run

1. Install the Java Development Kit (JDK).
2. Import or download this repository.
3. Open the project in Eclipse IDE.
4. Run Main.java as a Java Application.
